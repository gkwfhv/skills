# 论文中译风格规范

目标：读起来像中文作者写的，不像翻译腔。

## 一句话原则

先读懂整段，再用中文重新组织。不要按英文语序逐句搬。

## 句子

- 多用短句。一句话只讲一件事。
- 能用主动语态，就不用被动。
- 长句先拆：先背景/条件，后结论/动作。
- 不要连续堆定语。三个以上的“的”通常要拆。
- 少用抽象名词堆叠，多用动词。

## 禁用句式

| 不要写 | 改成 |
|---|---|
| 使得…… | 让…… / 结果…… / 于是…… / 直接删掉 |
| 让……成为可能 | 已经能做到 / 有了现实基础 |
| 本文提出一种……的方法，它…… | 我们做了…… / 我们提出…… |
| 值得注意的是 | 直接说结论 |
| 具体来说 | 做法是 / 拆开看 |
| 另一方面 | 反过来 / 而 |
| 通过……来…… | 靠…… / 用…… |
| 由……组成 | 包含…… / 分三块 |
| 被……所…… | 主动句 |
| 连续三个“的” | 拆句或改语序 |

## 术语

- 第一次出现：`中文（English）`；之后只用中文。
- `session`、`token`、`benchmark` 这类词，如果中文社区也这么用，可以保留。
- 同一篇里译名要一致。开始翻之前先列一张术语表。

## 结构

- 按原文顺序：标题、作者、摘要、正文、附录。
- 图表公式都要保留。图注翻译；表格用 Markdown 重排；公式用 LaTeX。
- 图放在第一次引用它的段落附近。
- 参考文献不逐条翻译。文末写一句：共多少条，完整列表见原文第几页，附 arXiv 链接。

## 译完自检

1. 通读一遍，把不像中文的句子重写。不要只改错别字。
2. 搜索禁用词。出现就改。
3. 检查图片路径、`$$` 是否成对、关键数字是否和原文一致。
4. 确认没有整段漏译。
5. 随机挑三段，遮住英文原文，只看中文：能不能读懂？像不像人话？

## 示例

英文：
> Existing systems either overwrite history to maintain an up-to-date map or
> store semantic snapshots without consistent cross-session object identity.

翻译腔：
> 现有系统要么覆盖历史以维护最新地图，要么存储没有一致跨会话物体身份的语义快照。

自然中文：
> 现有系统有两条路：一条不断覆盖历史，只保留最新地图；另一条存语义快照，但跨 session 的物体身份对不上。

英文：
> The robot uses a simple voxel-projection strategy to build an obstacle map.

翻译腔：
> 机器人使用一种简单的体素投影策略来构建障碍物地图。

自然中文：
> 障碍物地图怎么建？用简单的体素投影就行。
